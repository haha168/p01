## 快速開始

以靜態伺服器開啟（因需讀取 JSON，請勿直接用檔案協定開啟）：

```bash
# Python
python3 -m http.server 8080

# 或 Node
npx --yes serve -l 8080
```

瀏覽：`http://localhost:8080/`
